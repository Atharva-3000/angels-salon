# Angel Salon & Academy — Ratlam

Mobile-first static website concept for **Angel Salon & Academy**, 80 Feet Road, opposite Mahadev Mandir, Ratlam.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive styling
- `script.js` — smooth navigation + current year
- `assets/` — reserved for local assets if you want to self-host all images

## Hosting
This is plain HTML/CSS/JS. Upload the folder to Netlify, Vercel, GitHub Pages, cPanel/public_html, or any static host. No build step is required.
